# الأبرار للخدمات المنزلية — الموقع + لوحة التحكم

موقع احترافي عربي (RTL بالكامل) لشركة خدمات منزلية سعودية، مبني بـ **Next.js (App Router) + PostgreSQL (Drizzle ORM) + Tailwind CSS**، مع لوحة تحكم CMS كاملة لإدارة كل محتوى الموقع دون لمس الكود.

---

## ✨ المزايا

- **الواجهة العامة**: صفحة رئيسية + 6 صفحات خدمات (كهرباء، سباكة، دهانات وديكور، نقل عفش، تنظيف منازل، صيانة مكيفات) + من نحن + تواصل + مدونة CMS + سياسة خصوصية + شروط + 404.
- **لوحة تحكم عربية** (`/admin`): إحصائيات، إدارة الطلبات (حالات/ملاحظات/بحث/تصدير CSV)، إدارة الخدمات الست (نشر/ترتيب/صور/SEO/أسئلة/خطوات/مناطق)، مدونة بمحرر نصوص غني (TipTap)، مكتبة وسائط (رفع/ALT/حذف)، إدارة آراء العملاء والأسئلة الشائعة، تعديل الصفحات الثابتة، إعدادات الهوية (شعار/ألوان/أسماء)، إعدادات SEO (GA4/GTM/Search Console)، مستخدمين بصلاحيات (مدير/محرر)، تغيير كلمة مرور، ونسخ احتياطي.
- **SEO/GEO**: Meta فريد لكل صفحة، Canonical، Sitemap ديناميكي، robots.txt (مع السماح الصريح لبوتات الذكاء الاصطناعي)، llms.txt، Schema (LocalBusiness/Service/FAQPage/Article/Breadcrumb)، Open Graph، ALT text، إجابات مباشرة بأسلوب AEO.
- **التواصل**: فقاعة عائمة (واتساب/اتصال/طلب خدمة) مع رسالة واتساب تلقائية باسم الخدمة المتصفّح، نموذج طلب خدمة (اسم/هاتف/مدينة/خدمة/وصف) يحفظ في قاعدة البيانات مع حماية من السبوت ومعدل طلبات.
- **خريطة Google قابلة للتعديل** بالكامل من لوحة التحكم (رابط embed + العنوان النصي + توليد الرابط من العنوان).

## 🚀 التشغيل محليًا

```bash
# 1) التثبيت
npm install

# 2) ضبط المتغيرات — ملف .env
DATABASE_URL=postgresql://user:pass@host:5432/app_db
SESSION_SECRET=<سلسلة طويلة عشوائية>   # مهمة جدًا في الإنتاج

# 3) إنشاء الجداول
npx drizzle-kit push

# 4) حقن البيانات الأولية (خدمات، مقالات، آراء، أسئلة، صفحات، حساب المدير)
npx tsx src/db/seed.ts

# 5) التشغيل
npm run dev          # تطوير
npm run build && npm run start   # إنتاج
```

## 🗄️ مخطط قاعدة البيانات (Drizzle)

| الجدول | الغرض |
|---|---|
| `settings` | صف واحد: هوية الموقع، أرقام، ألوان، خريطة، SEO، GA/GTM |
| `services` | الخدمات الست (slug/name/صور/نصوص/قوائم JSONB: فرعية، مميزات، خطوات، مناطق، أسئلة) + SEO |
| `orders` | طلبات العملاء (حالة: new/in_progress/completed/cancelled + ملاحظات إدارية) |
| `posts` | المقالات (حالة draft/published + تصنيف + SEO + slug) |
| `media` | مكتبة الوسائط المرفوعة (`public/uploads`) |
| `testimonials` | آراء العملاء (تقييم/مدينة/نشر/ترتيب) |
| `faqs` | أسئلة الصفحة الرئيسية |
| `pages` | الصفحات الثابتة (من نحن/خصوصية/شروط) |
| `admin_users` | مستخدمو اللوحة (scrypt+salt، أدوار admin/editor) |

**ملاحظة للنشر**: عند استخدام Vercel أو استضافة SSG، تأكد أن الصفحات ديناميكية (وهي كذلك عبر `force-dynamic`) وأن `public/uploads` تبقى قابلة للكتابة (أو استبدل الرفع بـ S3/R2).

## 🌐 ربط الدومين والاستضافة

1. **الدومين**: من لوحة استضافتك (Vercel/Netlify/cPanel) أربط الدومين (مثال `www.alaabar-home.com`) ثم **حدّثه من**: لوحة التحكم ← الإعدادات ← الإعدادات العامة ← «رابط الموقع» (يُستخدم للـ Canonical وSitemap وOpen Graph).
2. **HTTPS**: مُفعّل افتراضيًا على Vercel/Netlify/cPanel.
3. **متغيرات البيئة في الإنتاج**: `DATABASE_URL` (قاعدة Postgres — Supabase/Neon/RDS) + `SESSION_SECRET` (أنشئها بـ: `openssl rand -hex 32`).
4. **Google Search Console**: أضف الدومين، انسخ قيمة التوثيق، وضعها في الإعدادات ← SEO ← Search Console.
5. **الخريطة**: من الإعدادات العامة → «خريطة Google» → أدرج عنوانك الحقيقي ثم «توليد رابط الخريطة»، أو ألصق رابط embed من Google Maps مباشرة.

## 💾 النسخ الاحتياطي

- زر «تنزيل نسخة احتياطية» في لوحة التحكم (يتطلب توفر `pg_dump` على الخادم).
- يدويًا: `pg_dump "$DATABASE_URL" > backup-$(date +%F).sql` — جدولة أسبوعية عبر cron أو Supabase/Neon backup.

## 🔒 ملاحظات أمنية مطبقة

- كلمات مرور بـ scrypt + salt، جلسات HMAC تنتهي بعد 12 ساعة (HttpOnly cookie).
- Rate limiting على الدخول والنماذج + Honeypot ضد السبوت.
- تحقق من صحة كل المدخلات على الخادم + تعقيم HTML (إزالة scripts و on* handlers).
- فصل الصلاحيات: «محرر» يدير المحتوى فقط، «مدير» يتحكم بالإعدادات والمستخدمين.
